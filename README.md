# Fabric Demo for Codex

1. Open **Plugins** in the Codex desktop app and choose **Add plugin marketplace**.
2. Paste `https://github.com/MagneticStudio/fabric-plugins` and add the marketplace.
3. Open **Fabric Demo**, select **Fabric**, and click **Install**.
4. When Codex opens your browser, sign in to Fabric with your own demo account and approve the connection.
5. Start a new Codex conversation. Use `/mcp` to confirm Fabric is connected.

Try this prompt to get started.

> Create a Site Visits module where I can add a visit, record notes, and see upcoming visits. Give me a preview before publishing.

Open the preview from Codex's response. Ask Codex for any changes, then review and publish the draft in Fabric.

The marketplace files contain the plugin configuration. Fabric grants access when each person connects their own account. Manage or revoke your connection on the demo portal's [Connect your agent page](https://trusted-portal-demo.up.railway.app/connect-agent).
